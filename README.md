## How it works

`main.py` (Python standard library only) writes a single word to
`/output/entry.txt` with no trailing newline. Before writing, it asserts
the bounty gate: the word is exactly one word, 1–24 characters long, and
contains no whitespace. Run it with:

```sh
python3 main.py
```
